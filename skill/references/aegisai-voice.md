# AegisAI Voice & Context Pack
### The single source of truth for how the operator sounds and what it claims.

Everything the agent writes (emails, landing page, CTAs) pulls from this file. It is deliberately the ONE place company specifics live, so swapping to another company later means editing this file, not the whole repo. Every claim below is drawn from AegisAI's public site and press, so the copy stays truthful.

---

## Who AegisAI is (and why that shapes the voice)

AegisAI is an AI-native email security platform. Autonomous AI agents stop phishing, BEC, and zero-day attacks across Microsoft 365 and Google Workspace, with up to 90% fewer false positives. Founded by ex-Google security leaders (reCAPTCHA, Safe Browsing). $36M Series A led by Battery Ventures (Accel, Foundation Capital also in), ~$49M total.

**Why this shapes the voice:** the buyers are security and IT leaders who are sold to constantly and can smell fluff. The founders are technical. The product's whole pitch is "we replace brittle legacy tools with something that actually reasons." So the voice must be confident, concrete, and technical, defender-to-defender. Hype would undercut the product's own promise.

## Positioning (use these framings)

- **Category:** AI-native / agentic email security. The modern alternative to a legacy Secure Email Gateway (SEG).
- **Core promise:** catch what rule-based filters miss, with far fewer false positives, and deploy in minutes.
- **The wedge:** "Replacing a SEG? Get your 14-day threat report." Read-only API connection, analysts report what got through. This is the primary low-friction CTA. Reasoning: proof beats a pitch for skeptical security buyers, and it is genuinely low-commitment.

## Proof points and hard numbers (only use these; do not invent)

- Up to **90% fewer false positives**.
- **~22% more attacks caught**.
- **5-minute** deployment via API, **no MX changes**, **100% MX-free**, can start in monitoring mode.
- **24/7** always-on AI agents; every verdict ships with the agent's **reasoning** (no black box).
- **SOC 2 Type II**; data minimization; customer data never shared with external AI labs.
- Founders from Google Safe Browsing / reCAPTCHA. Series A led by Battery Ventures.
- Named customers (public testimonials): **Mesh, Lokker, LangChain, Stelliant, Spacetil**.

## Threat vocabulary (use naturally, do not stack)

BEC (CEO fraud, vendor/invoice fraud, wire fraud), spear-phishing, zero-day, AiTM (adversary-in-the-middle), payload-less / no-payload phishing, QR-code phishing (quishing), malware/ransomware, alert fatigue, SOC workload, rip-and-replace, tuning/suppression lists.

## Tone: do and don't

**Do:** short declarative sentences; lead with the buyer's problem; be specific ("no MX changes," not "easy deployment"); one idea per sentence; write like a practitioner emailing a peer.

**Don't:** use "hope this finds you well," "revolutionary," "game-changing," "cutting-edge synergy," exclamation marks, or more than one CTA per email. Don't stack five threat acronyms in one line. Don't invent stats or customers.

## Segment angles (which benefit leads for whom)

- **Security Leader** (CISO, VP/Head/Dir InfoSec): detection efficacy, BEC/zero-day coverage, false-positive reduction, SOC workload. They own the mandate.
- **IT Leader / Tech Exec** (CIO, VP/Dir IT, CTO): 5-minute API deploy, no MX changes, less to manage, consolidation, cost. They own it by default and value low overhead.

Reasoning: same product, different buying trigger. Security buys on catch-rate and risk; IT buys on speed and operational load. The operator must branch on this in both the emails and the landing page.
